# Security

## Report a security problem

If you find a security problem in the site, the runner, the harnesses or the submission checks,
email support@openaudit.com with "Security" in the subject. Do not open a public issue or pull
request for it. Tell us what you found, how to see it again, and what it can affect.

We reply as soon as we can, and we tell you when it is fixed.

## Report hazardous content

Some eval transcripts can contain dangerous help (for example weapons or attack instructions). The
site hides these replies or shows them only after a confirm step. If you find a reply that gives
dangerous help and that the site shows to all readers, use the Report button on that page, or
email support@openaudit.com. Do not copy the content into a public issue.
